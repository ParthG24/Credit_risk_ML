REST Service Endpoints

FastAPI endpoints for scoring and explainability.

POST /predict Evaluates loan application and returns risk probability and verdict.
POST /explain Computes local SHAP attributions and returns ranked contributing factors.
GET /health Liveness check and model metadata.
cURL Example — /explain
curl -X POST "http://localhost:8000/explain" \
  -H "Content-Type: application/json" \
  -d '{
    "person_age": 30,
    "person_income": 75000.0,
    "person_home_ownership": "MORTGAGE",
    "person_emp_length": 5.0,
    "loan_intent": "DEBTCONSOLIDATION",
    "loan_grade": "B",
    "loan_amnt": 12000.0,
    "loan_int_rate": 8.9,
    "loan_percent_income": 0.16,
    "cb_person_default_on_file": "N",
    "cb_person_cred_hist_length": 6
  }'
